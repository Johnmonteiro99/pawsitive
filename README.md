## 🎯 Project Purpose

This project was created for a real pet-sitting business to provide an online presence and make it easier for potential clients to learn about services and request bookings.

The focus was on:

* Simplicity and clarity
* Mobile responsiveness
* Clear user flow from landing → services → contact
